# UsefulAIKey

Let's be honest, no one uses Microsoft Copilot. The Copilot button is used by no one on PCs that have it. 

If you remove the Copilot app, you can customize what it does by associating it with a compatible app. Alas, the few compatible apps that allow you to configure the button to launch myriad actions all cost money despite being incredibly simple.

This project aims to fix that.
